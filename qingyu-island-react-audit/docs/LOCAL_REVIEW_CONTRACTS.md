# 0.6.2-audit.1 本机审阅版：当前生效的交互边界

本文件是对原 v0.6 文档的本轮工程落实；不是新增疗效证据，也不是生产系统认证。
优先级：实际代码和本轮测试记录 > 本文件 > 旧版本规划。发现冲突应停止发布，不用文案掩盖。

## 1. 本地求助
孩子看到的是“请把这张卡片给身边可信的大人看”。它没有跨设备发送，也没有送达、已读、即将到场动画。
拥抱只是可选行为；坐在旁边或说话也可以。没有合适成人时不要求孩子只等待屏幕。
想念仅在本次页面内存中，刷新或关闭页面后清除。点击本地结束不表示照顾质量已被验证。

## 2. 三轴模型
通信、照顾责任、真人会合独立记录。`SENT` 必须来自明确传输回执；在线标记本身无效。
设备回执不证明人已读；转交请求不证明接应人接受；会合枚举必须带来源。
成人自报只能以自报措辞出现，不自动退场；“本机结束”可以结束流程但不证明到场。
不知道大人有没有来时，不写“还没到”“正在路上”“没有看见”“失约”。
真实远程适配器尚未接入。当前只有成人工作台能操作模拟状态，儿童入口不能操作这些按钮。

## 3. 安全边界与课程
已标记伤害的故事不显示伤害行为的利弊称量；允许保护身体、离开、求助。
事实/感受/猜测练习不用于驳斥孩子的伤害披露。理解原因不等于认可侵犯。
家庭内容默认关闭；每次进入需通过本机家长门确认共读。家长 PIN 不能证明实际成人在场。
“看过故事”不等于掌握方法；人工观察中 F1–F7、P0–P3、提示次数和任务结果分别记录。
P0–P3 是本任务的提示类别，不能跨任务平均成能力分数。退出不是孩子能力失败。
既有 28 片迁移元数据的完整呈现、独立保留题污染控制与真实迁移验证仍需后续实现/研究。

## 4. 家长门与数据
默认页面内存；只有成人明确许可才保存四字段：
`version`、`completedLeaves`、`careWeek`、`familyContent`。
上述本地存档为未加密 localStorage，不防护设备持有人。真实儿童试点前须进一步审查。
天气、想念、星光拼图、人工观察与自省不因此上传或持久化。
PIN 以随机盐 PBKDF2 哈希保存在当前标签页 sessionStorage，解锁状态仅在内存。
回到儿童端、闲置 5 分钟、页面隐藏都会锁定成人工作台。它是防误入，不是监护人身份认证。
关闭 PIN 弹窗或组件卸载后，尚未完成的异步校验不得重新打开成人工作台。
清除只删除已识别的小岛本机数据；不替用户删除下载文件，也不能删除未知云副本。

## 5. 后端与发布
所有 `/api` 路径明确返回 `503 API_DISABLED_PENDING_VERIFIED_AUTH`。
旧 Firebase 占位适配器构造时拒绝调用，不能提供假的云成功响应。
真正上线需验证签名/过期等身份信息并从服务端可信数据判断家庭成员关系，不能信任客户端自报 role。
本轮不部署、不配置真实云数据库、不公开真实儿童数据，也没有回写 Drive。
