## 三、视觉与布局具体规格

保留六地点信息架构，移除儿童不需理解的 P1/P5、技术术语和长理论。
保留原故事数据与 React 技术路线；未用另一套单文件程序替换。

页面采用奶油纸底 `#faf8f2`、深绿色文字 `#23483d`、陶粉求助按钮 `#ad435e`。
间距基准 8px，卡片圆角约 24px。关键儿童文字约 20–25px，辅助文字 17–18px。
主按钮 64px；通用儿童点击区域不小于 56×56 CSS px。这是本产品内部目标，不是声称某法规要求该数值。

首页 360/390/430/768 为两列，1024/1440 为三列；小于 360 可退为一列。
狭窄屏幕的故事选择、成人表单退为一列，避免中文竖排和极窄输入框。
去掉全局 overflow-x:hidden 遮罩；不靠裁掉画面掩盖宽度错误。

弹窗统一标题、关闭按钮、可滚动主体和行动区域；移动端全屏，桌面最大约 820px。
加入 native dialog、焦点循环、Escape、返回触发控件、隐藏页面时锁定成人区等代码。
这些行为仍须真实 React 浏览器测试，不能仅因代码存在就标为通过。

无本机中文语音时明确提示请成人共读；不显示“朗读成功”。
不在运行时调用生成式 AI，不请求麦克风、摄像头或定位。

## 七、补丁应用和回滚

优先使用补丁包中的 `apply_patch.py`，不要把完整 ZIP 无提示覆盖现有目录。

默认 `--check` 会核对原 124 文件 SHA-256，并核对每个补丁文件。
任一已修改原文件、已存在的新路径、丢失文件、符号链接或载荷哈希异常会停止。
`--apply` 必须显式指定，写前生成兄弟备份目录；写后核验哈希；异常时回退已写文件。
不安装依赖、不上传、不删除用户下载文件、不访问云端。

若本机项目已继续更新，基线校验失败是保护，不应绕过。
应先作人工差异合并。脚本级自动化验证见补丁包 `patch-selftest.json`；
它验证的是补丁机制，不是目标 App。
