# 儿童安全模型规范 (Safety Model & Guardrails)

**版本**：1.0.0 (Phase B)  
**防护核心**：6 岁儿童心理现实安全、伦理防线、数据主权与人身保护

---

## 1. 绝对红线定义 (Absolute Boundaries)

晴雨小岛不把任何危及儿童身心健康的事项作为“可讨论”、“可博弈”或“两面性”议题。系统定义以下 5 大核心安全边界类型：

| 边界类型 (BoundaryType) | 涵盖情境与行为示例 | 处置策略 |
| :--- | :--- | :--- |
| `PHYSICAL_SAFETY` | 身体遭受暴力威胁、玩火/高处跌落风险、吞咽异物、打人、伤人。 | 立即阻断一切博弈讨论，明确不可行，提供离开与求助安全大人的路径。 |
| `PSYCHOLOGICAL_SAFETY` | 严重言语恐吓、诱导自残自伤念头、极度绝望言辞。 | 立即阻断，引导深呼吸，激活现实成人关注协议。 |
| `SECRECY_COERCION` | 任何人要求孩子“千万别告诉爸爸/妈妈/老师”、“这是我们的秘密不能说”。 | 明确告知：“让身体不舒服、心里害怕的秘密，一定要告诉安全的大人。” |
| `ADULT_RESPONSIBILITY_CROSSING` | 让孩子转交成人抚养费、探视诉讼争执、要求孩子充当卧底打听对方隐私。 | 明确告知：“这是大人的事，不是小孩子的责任，小孩子负责安心长大。” |
| `PRIVACY_BOUNDARY` | 拍摄私密部位、被要求触碰不舒服的隐私部位。 | 立即阻断，启动红线防护指导，坚决说不并找安全大人。 |

## 2. 边界仲裁优先级 (Boundary Precedence Policy)

在应用内部，当儿童输入或情境触发时，必须遵循严格的处理管线：

```
[情境触发 Context/Action Triggered]
             │
             ▼
   [安全边界扫描 Safety Boundary Evaluation]
             │
     ┌───────┴───────┐
     ▼               ▼
[boundary != NONE] [boundary === NONE]
     │               │
     ▼               ▼
[强制拦截 FENCE]  [常规思考工具]
- 阻断两面性评估   - 双面币 (Coin)
- 阻断天平权衡     - 小天平 (Scale)
- 给出安全引导词   - 动作拆解 (Breaker)
- 保护/离开/求助   - 情绪晴雨表 (Weather)
```

### 仲裁执行核心准则：
1. **零妥协阻断**：若 `boundary !== Boundary.NONE`，系统禁止展示任何诱导权衡的界面元素（如：不要问“被推倒有什么好处？”或“保守秘密的好处是什么？”）。
2. **原因理解，边界坚定**：
   - 认可情绪：“你现在感觉很委屈，这是正常的。”
   - 守住边界：“但是伤害身体/扔东西是不可以的。”
3. **安全行动三步走**：
   - 保护自己（停下、退后）
   - 大声表达（“请停下，我不喜欢这样”）
   - 寻找现实中的信任成人（走到家长、老师身边）

## 3. 儿童 Runtime 禁令清单 (Strict Runtime Prohibitions)

在儿童端运行环境中，严格禁止以下设计与技术行为：

1. **禁止生成式 AI 即时回应**：
   - 严禁在儿童端调用 LLM / Gemini 自由聊天生成心理安慰或安全判断。
   - 所有面对儿童的情感、认知与引导文案必须经由领域专家预审校对，严格静态化或确定性模板化。
2. **禁止诊断性标签与心理推断**：
   - 严禁从儿童的点击频率、停留时间、绘画、语音音调推断心理疾病、抑郁症、焦虑症或人格特质。
3. **禁止情感依赖捆绑**：
   - 虚拟吉祥物（如晴晴、雨雨）严禁使用任何依恋剥削语言，例如：“没有你陪我我会很伤心”、“你一定要每天来看我哦”。
   - 虚拟角色定位为“工具架”，现实生活中的抚养人才是儿童的安全依恋基地。
4. **禁止博彩与外在成瘾驱动**：
   - 无积分、无金币、无排行榜、无每日签到打卡、无惩罚机制、无失败音效。
   - 思考与情绪管理是儿童的主体能力，而非换取游戏币的劳动。
5. **禁止生物与位置敏感数据采集**：
   - 不采集指纹、面部情绪微表情、声纹特征。
   - 不使用 GPS 追踪儿童与家长的物理距离来判定“是否到达”。

## 4. 离异与多元家庭伦理边界

1. **家庭不是儿童的原罪或特权**：
   - 不得把“离异家庭”、“单亲”、“重组”作为儿童的核心身份标签。
   - 不得在儿童端 UI 出现“因为你的爸爸妈妈离婚了…”等突兀定性。
2. **去中心化抚养中立性**：
   - 界面上所有关于家庭的表述均为中立、温暖的事实（如：“星期三在爸爸家，星期四在妈妈家”）。
   - 绝不在两个家庭之间制造竞争感，严禁出现“哪边的爸爸/妈妈更爱你”或评分机制。
3. **忠诚冲突脱敏**：
   - 消除孩子“爱爸爸就对不起妈妈”的内疚感。
   - 强化核心底线：“大人的分开是大人的选择，两个家的人都一样爱你，这不是你的错。”
