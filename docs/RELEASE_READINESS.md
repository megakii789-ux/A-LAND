## 4. v0.7 完整可玩体验与首批可用性测试收束规划 (v0.7 Scoped Playable Experience Roadmap)

为了高安全、高质量且契约守信地推进 6 岁真实儿童可用性测试与亲子共玩验证，建议将下一发布版本（v0.7）严格收束为：**3 个完整可玩体验单元 + 2 个未训练新情境 + 成人共玩支持**。

### A. 首批制作与可玩互动范围 (First-Batch Interactive Scope)
1. **可玩互动单元 (3 个)**:
   - **《杯子比较》 (杯子大小大讨论)**: 基于物与名（`cup-size`）故事叶，支持拉动标尺测量杯子真实物理高度，并可点击切换到“小积木”（大山）和“小水桶”（一滴水）视角比照。每一次操作都带来具体的屏幕大小透视与刻度标尺变化，用以训练“分”与“通”，而非弹窗说教。
   - **《蜡笔取证》 (谁拿了我的蜡笔)**: 在同伴疑心、挫折场景下，支持孩子点选“桌上的鞋印/真实的画画进展（事实）”与“他是不是故意针对我（猜想）”。提供物理放大镜扫过卡片显现细节的“放大镜取证”动效，让事实与猜想的划分完全可感。
   - **《小船协商》 (两只动物想坐同一艘玩具船)**: 在玩具共享冲突中，孩子可以用手拖放不同做法砝码（如“轮流开”、“一起造大码头”）放上小天平，小天平会随着砝码产生逼真的向下倾斜偏转，并显示每种做法各自对应的具体“好处”与“代价”。
2. **未训练的 Held-Out 迁移新场景 (2 个)**:
   - 包含 2 个全新表面情境、但与前述训练叶共享完全相同“关系结构”的 Held-Out 检验叶，作为无言语诱导、无命名提示的纯粹静默迁移证据（`transfer evidence`）观察卡。
3. **成人共玩支持与示范 (Co-Play Guidance)**:
   - 针对三种核心家长示范行为提供一键式交互卡片和对照：
     - **不抢答**: 允许并赞赏孩子用自己的探索节奏去试错、点按与反复重听。
     - **允许不知道**: 当孩子面临认知纠结或求助时，示范大人的真诚话术：“爸爸/妈妈现在也不太确定呢，我们一起拿放大镜去找找线索吧！”
     - **表达未被回应后的支持**: 当不在身边的抚养人因突发状况未能及时响应即时抱抱时，在场方引导词：“虽然现在没能收到消息，但这100%不代表你不重要。来，妈妈/爸爸给你一个大大的现实拥抱。”

### B. 语音与画面质量验收标准 (Asset Quality Standards)
- **语音控制 (40-60 条短旁白)**:
  - 覆盖通用导航、出错降级、操作提示和主角动物温和话术。
  - **声音播放契约**：必须支持 **重听、随时停止、切场景即刻中断**。当孩子点击切换场景或选项时，上一轨声音必须立刻静音并释放，绝不允许多轨声音叠加重叠。
- **画面精度 (12-18 张分层原画)**:
  - 锁定小象、松鼠、小兔子、小熊等固定角色设定。
  - 孩子必须能用眼睛直接在画中看懂发生了什么事件，不依赖任何文字。前后对比时，事物的大小比例、位置变迁绝对不能画错。
- **儿童短片**:
  - 首批阶段特意保留为 **零 (0)**。去掉它绝不损失必要信息，遵循极简、低视觉刺激原则，暂缓视频与无限加载动效。

### C. 科学制作与共玩验证顺序 (Development & Testing Protocol)
```
[简单图形/草图 + 临时配音] -> [验证交互热区/状态切换/声音中断] -> [固定精简脚本] -> [生产正式原画与旁白] -> [接入应用回归测试]
```
1. **第一步 (草案验证)**: 用无色线稿、占位符几何体及开发者自己用麦克风录制的临时人声验证 360px/390px Viewport 下的交互，测试热区是否 >= 56px 且无多轨声音重叠。
2. **第二步 (固定脚本)**: 根据草案中孩子的反应，剔除复杂的书面语，精简文字到仅起语音辅助作用，固化最后的文案。
3. **第三步 (生产正式插画与旁白)**: 录制去游戏化、温暖去压力、不含价值评判的专业旁白，以及高保真、低饱和度的分层插画。
4. **第四步 (接入真实应用与回归测试)**: 通过 AppContext 适配器将高保真素材注入渲染层，确保离线与在线双端通信通过 Playwright E2E。

### D. 第一轮 5-8 个家庭共玩的核心观察重点 (Co-Play Evaluation Metrics)
第一轮共玩测试的核心，**绝对不是“孩子玩了多久” (不盲目追求停留时间)**，而是对以下设计安全问题的精准回答：
- 孩子在不识字的情况下，是否看懂了画里发生了什么？
- 孩子是否清楚屏幕里哪里是可以用手指动一动的？
- 动作发生之后，孩子有没有注意到变化？
- 孩子是否愿意自发尝试第二种不一样的解决办法？
- 孩子是否能在玩完一轮后，自在、温和地主动停下来，回到大人的现实拥抱中？

*5–8 个家庭的定性观察仅用于迭代上述人机交互与无障碍设计，任何时候均不可以用此定性测试作为“游戏促进了迁移”或“产品改善了儿童心理状态”等过度宣传的科学依据。*
