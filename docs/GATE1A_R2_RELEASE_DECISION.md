## 三、严格纪律约束与发布禁令

本轮验收虽然确认代码在端侧闭环与静态安全模型上完成了 P0 整改，但**绝对不构成最终儿童安全上市许可**。必须严格遵守以下禁令：

1. **禁止发布生产环境**:
   - 不得将当前版本打包部署至对外商业或生产渠道。
2. **禁止修改线上 Firebase 配置与部署规则**:
   - 不得调用 `deploy_firebase` 将未在正式 Emulator 环境完成端到端验证的规则部署到生产项目。
3. **禁止自动同步或推送到远程 GitHub `main`**:
   - 保持所有改动在本地沙箱隔离，等待独立审计审查。
4. **禁止宣称“儿童安全合格”**:
   - 必须向所有相关方如实披露：当前求助功能为“端侧无真实中继状态”（明确告知孩子找身边的大人），真实远程端对端救助链路需待认证与通信基础设施建立后方能实现。
5. **禁止擅自启动 Gate 1B**:
   - 当前回合在此完全停止，等待用户授权与红队审查。
