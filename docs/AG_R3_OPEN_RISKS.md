# 晴雨小岛 A-LAND｜第三轮审计残余风险清单 (AG-R3 Open Risks)

**审计评估时间**：2026-10-14  
**风险等级定义**：高危 (P0)、中危 (P1)、低危 (P2)、观察项 (Info)

---

## 一、当前残余风险清单

### 1. [中危 · R-01] 外部独立资质专家伦理签署尚未就位
- **风险描述**：代码已实现 6 要素内容审核登记与防虚构黑名单，但生产级交付仍需外部儿童心理学、发展心理学执业专家的正式签署核验单。
- **缓解机制**：
  - 敏感场景（家庭转换、同伴询问、父母电话延迟等）在未获专家核验签署前，由 `classifyLeafScenarioAccess` 强制降级为“待独立审查 · 需大人共读”；
  - 独立审核中心不编造专家委员会或签字；
  - 运行时禁止未经审查的内容自动宣告儿童已具备心理韧性。

### 2. [中危 · R-02] 跨设备远程即时求助物理中继尚未建设
- **风险描述**：当前为纯本地高安全运行模式（Local-Only），无合规的云端 Firebase Push / APNs / SMS 远程中继通道。若 6 岁儿童独处遭遇紧急情况，无法直接呼叫不在身边的大人。
- **缓解机制**：
  - 遵守真实通信契约，求助键调整为“当面求助卡”，点击直接在屏幕出示给身边看得见的大人；
  - 明确告知孩子“这里不会发送远程通知，请直接拉拉身边大人的衣角”；
  - 引导孩子在身边大人忙碌时直接寻找老师或安全成年人；
  - 严禁在 UI 界面展示“已送达”、“大人马上来”等任何虚假承诺。

### 3. [低危 · R-03] 浏览器无痕模式下 SessionStorage 与 LocalStorage 隔离
- **风险描述**：在极少数严格隐私浏览模式或禁用本地存储的环境下，localStorage 写入可能抛出 `QuotaExceededError` 或拒绝访问。
- **缓解机制**：
  - 代码在 `profileStore.ts`、`AppContext.tsx`、`parentAccess.ts` 中实现全量 try-catch 降级；
  - 在存储不可用时，优雅回退至内存会话（In-Memory Session），确保核心故事与平静角呼吸功能正常运行。

### 4. [环境约束 · R-04] 沙箱容器缺乏 Playwright 浏览器二进制与 Java 虚拟机
- **风险描述**：开发容器缺少 Chromium 运行依赖库与 Java 运行时，导致自动化真实浏览器 E2E 与真实的本地 Firebase Firestore Emulator 无法在本次构建环境中端到端执行。
- **缓解机制**：
  - 保持诚实审计记录，不使用假桩冒充通过；
  - 在 CI/CD 物理流水线中配置标准 Playwright 与 Java 运行容器作为门禁前置步骤。
